# Компоненты и движение

Источник значений оформления — `src/styles/global.css`: слои reset/theme/layout/components/responsive. Семантические цвета (`--page`, `--surface`, `--text`, `--muted`, `--line`, `--accent`, `--on-accent`) и шрифты заданы в `:root`. Новые компоненты используют эти токены. Согласованное направление и ограничения контента находятся в [спецификации](portfolio-spec.md).

## Что переиспользовать

| Компонент | Ответственность |
|---|---|
| `src/layouts/BaseLayout.astro` | Метаданные, язык, общий фон, skip link, шапка/подвал и подключение движения |
| `src/components/Header.astro` | Навигация и перевод текущего кейса; мобильная навигация переносится в строку |
| `src/components/Footer.astro` | Общий контактный блок с почтой, Telegram и GitHub; подпись и ссылка наверх |
| `src/components/HeroBadge.astro` | Бейдж с котиком, статичный fallback и кнопка переворота |
| `src/components/ProjectRow.astro` | Карточка с обзором и вкладом, нативными кнопками переворота и ссылками на кейс |
| `src/components/MotionHeading.astro` | Семантический заголовок с отдельными словами для последовательного появления |

Кнопка основного действия — ссылка `.primary-link`, вторичные действия — `.text-link`. Бейдж использует Three.js, а заголовок ElasticMesh — WebGL2. Их нативные адаптации из React Bits находятся в `src/lib/effects`, лицензии — в `public/licenses`. Контроллер `src/scripts/showcase.ts` подгружает эффекты только для видимого содержимого; при ошибке остаются HTML-текст и изображение. Цвета сцены берутся из текущей палитры. React и Motion не подключаются. Клавиатурный фокус виден через `:focus-visible`. Контент кейсов остаётся Markdown, без UI-разметки внутри описаний.

## Сценарий движения

Контактный футер одинаков на главной и в кейсах: слева приглашение обсудить работу и короткое пояснение, справа — три строки ссылок с названием канала и видимым адресом. На мобильном блоки идут друг под другом. Контакты берутся из `src/data/profile.ts`, переводы — из `src/i18n/ui.ts`; ссылки доступны сразу без анимации и JavaScript. Почта использует `mailto:`, Telegram — `https://t.me/`, GitHub ведёт в личный профиль.

`src/scripts/motion.ts` управляет движением через browser APIs. Первое появление имени раскрывает строки; прокрутка удерживает `.hero-scene` (тексты, действия, бейдж и стек) на фоне и плавно затемняет её, пока следующий раздел поднимается поверх. Положение удерживает нативный CSS `position: sticky` у `.hero`; скрипт меняет только прозрачность `.hero-scene` и не компенсирует прокрутку transform. Начало затухания измеряется по обычному потоку `main`, а не по закреплённому блоку; после перекрытия сцена исчезает. На длинной мобильной сцене эффект отложен, чтобы все её части успели войти в окно. Заголовки появляются по словам, карточки проектов — последовательно снизу, выступления — снизу, образование — с противоположной стороны. Направления различаются по роли элемента. Появление рассчитывается из текущей видимой позиции и обращается при прокрутке обратно; оно не завершается навсегда после первого пересечения viewport.

Прокрутка остаётся нативной: без перехвата колеса, закреплённых заставок и задержки перехода к проектам. Без JavaScript всё содержимое видно. Reduced motion отключает появления, уход первого экрана и движение фона. Клавиатурный фокус возвращает сцене читаемость и приводит выбранное действие в окно. Автоматическое появление бейджа и движение орбит короткие, без бесконечных циклов и кнопок паузы. Общий фон не имеет краёв секции и не увеличивает ширину документа.

Длительности и easing задаются токенами движения в CSS; скрипт читает их для согласованного темпа. При добавлении эффекта сначала выбери существующий сценарий, затем проверь мобильную геометрию и читаемость.

На широком экране отступы и размер имени учитывают высоту окна через `svh`: строка стека видна сразу, без первого подготовительного скролла. Во время перекрытия сцена сохраняет исходную вертикальную позицию — нативное закрепление и изменение прозрачности, без дополнительного сдвига вверх. Высота содержимого не ограничена: на мобильном, при увеличении текста или в очень низком окне длинная сцена сначала проходит через окно.

Навигация закреплена у верхнего края и не скрывается при прокрутке. Её фон вынесен в псевдоэлемент на всю ширину окна; общие отступы задаёт `--page-gutter`. Первый экран — отдельная `.hero-scene`, поэтому навигация не участвует в его исчезновении. Пункты меню на главной — локальные якоря; `scroll-padding-block-start` учитывает реальную высоту шапки. Нативная плавная прокрутка отключается при reduced motion.

Световой акцент слушает `pointermove` на `document` и использует координаты окна. Физика бейджа остаётся локальным эффектом первого экрана; свет продолжает следовать за курсором в проектах, контактах и кейсах. Reduced motion отключает оба эффекта, touch-ввод не запускает фонарик.

## Новые эффекты

Палитра: `--page: #02343F`, `--accent` и `--text: #F0EDCC`, вторичные поверхности — оттенки бирюзового. Фон сохраняет спокойную сетку, свет и орбиты этой палитры, без дополнительного фонового WebGL.

`src/styles/showcase.css` оформляет карточки, блик, бейдж и магнитные кнопки. Карточка имеет единую intrinsic-высоту обеих сторон: длинный перевод или вклад не обрезаются. Скрытая сторона получает `inert` и `aria-hidden`; фокус переходит на кнопку видимой стороны, Escape возвращает обзор. Reduced motion переключает стороны без вращения. Без JS оба текста и ссылки доступны последовательно.

Тяжёлые WebGL-адаптации изолированы за mount/dispose. Бейдж прекращает физику в покое, вне окна и на скрытой вкладке; при изменении reduced motion ресурсы освобождаются. На touch перетягивание не перехватывает прокрутку. Параметры портов и лицензионные условия описаны в `docs/third-party.md`.

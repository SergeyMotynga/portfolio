# Компоненты и движение

Источник значений оформления — `src/styles/global.css`: слои reset/theme/layout/components/responsive. Семантические цвета (`--page`, `--surface`, `--text`, `--muted`, `--line`, `--accent`, `--on-accent`) и шрифты заданы в `:root`. Новые компоненты используют эти токены. Согласованное направление и ограничения контента находятся в [спецификации](portfolio-spec.md).

## Что переиспользовать

| Компонент | Ответственность |
|---|---|
| `src/layouts/BaseLayout.astro` | Метаданные, язык, общий фон, skip link, шапка/подвал и подключение движения |
| `src/components/Header.astro` | Навигация и перевод текущего кейса; мобильная навигация переносится в строку |
| `src/components/Footer.astro` | Подпись и ссылка наверх |
| `src/components/HeroSystem.astro` | Демонстрационная схема API/данные/ML; состояние сцены и пауза |
| `src/components/ProjectRow.astro` | Нативный `details`: заголовок, краткое описание, вклад, стек и переход к кейсу |
| `src/components/MotionHeading.astro` | Семантический заголовок с отдельными словами для последовательного появления |

Кнопка основного действия — ссылка `.primary-link`, вторичные действия — `.text-link`. Схема использует настоящие кнопки с `aria-pressed`; выбранное состояние показывает также рамка. Клавиатурный фокус виден через `:focus-visible`. Контент кейсов остаётся Markdown, без UI-разметки внутри описаний.

## Сценарий движения

`src/scripts/motion.ts` управляет движением через browser APIs. Первое появление имени раскрывает строки; прокрутка плавно убирает имя вверх и проявляет следующие разделы. Заголовки появляются по словам, строки проектов — последовательно сбоку, выступления — снизу, образование — с противоположной стороны. Темп и направления различаются по роли элемента, а не случайно.

Прокрутка остаётся нативной: без перехвата колеса, закреплённых заставок и задержки перехода к проектам. Без JavaScript всё содержимое видно. Reduced motion отключает появления, уход заголовка и движение фона. Клавиатурный фокус отменяет скрытие интерактивного блока. Пауза схемы останавливает её поток. Общий фон не имеет краёв секции и не увеличивает ширину документа.

Длительности и easing задаются токенами движения в CSS; скрипт читает их для согласованного темпа. При добавлении эффекта сначала выбери существующий сценарий, затем проверь мобильную геометрию и читаемость.

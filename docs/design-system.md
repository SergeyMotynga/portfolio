# Компоненты и движение

Источник значений оформления — `src/styles/global.css`: слои reset/theme/layout/components/responsive. Семантические цвета (`--page`, `--surface`, `--text`, `--muted`, `--line`, `--accent`, `--on-accent`) и шрифты заданы в `:root`. Новые компоненты используют эти токены. Согласованное направление и ограничения контента находятся в [спецификации](portfolio-spec.md).

## Что переиспользовать

| Компонент | Ответственность |
|---|---|
| `src/layouts/BaseLayout.astro` | Метаданные, язык, общий фон, skip link, шапка/подвал и подключение движения |
| `src/components/Header.astro` | Навигация и перевод текущего кейса; мобильная навигация переносится в строку |
| `src/components/Footer.astro` | Подпись и ссылка наверх |
| `src/components/HeroSystem.astro` | Схема API-, сервисного и DB-слоёв; направление запроса и ответа |
| `src/components/ProjectRow.astro` | Нативный `details`: заголовок, краткое описание, вклад, стек и переход к кейсу |
| `src/components/MotionHeading.astro` | Семантический заголовок с отдельными словами для последовательного появления |

Кнопка основного действия — ссылка `.primary-link`, вторичные действия — `.text-link`. Схема не содержит элементов управления; подписи обозначают архитектурные слои, а стрелки — направление обмена. Клавиатурный фокус виден через `:focus-visible`. Контент кейсов остаётся Markdown, без UI-разметки внутри описаний.

## Сценарий движения

`src/scripts/motion.ts` управляет движением через browser APIs. Первое появление имени раскрывает строки; прокрутка удерживает `.hero-scene` (тексты, действия, схему и стек) на фоне и плавно затемняет её, пока следующий раздел поднимается поверх. Положение компенсируется transform без изменения скорости нативной прокрутки; после перекрытия сцена исчезает. На длинной мобильной сцене эффект отложен, чтобы все её части успели войти в окно. Заголовки появляются по словам, строки проектов — последовательно сбоку, выступления — снизу, образование — с противоположной стороны. Направления различаются по роли элемента. Появление рассчитывается из текущей видимой позиции и обращается при прокрутке обратно; оно не завершается навсегда после первого пересечения viewport.

Прокрутка остаётся нативной: без перехвата колеса, закреплённых заставок и задержки перехода к проектам. Без JavaScript всё содержимое видно. Reduced motion отключает появления, уход первого экрана и движение фона. Клавиатурный фокус возвращает сцене читаемость и приводит выбранное действие в окно. Автоматическая подсветка связей и движение орбит короткие, без бесконечных циклов и кнопок паузы. Общий фон не имеет краёв секции и не увеличивает ширину документа.

Длительности и easing задаются токенами движения в CSS; скрипт читает их для согласованного темпа. При добавлении эффекта сначала выбери существующий сценарий, затем проверь мобильную геометрию и читаемость.

Навигация закреплена у верхнего края и не скрывается при прокрутке. Её фон вынесен в псевдоэлемент на всю ширину окна; общие отступы задаёт `--page-gutter`. Первый экран — отдельная `.hero-scene`, поэтому навигация не участвует в его исчезновении. Пункты меню на главной — локальные якоря; `scroll-padding-block-start` учитывает реальную высоту шапки. Нативная плавная прокрутка отключается при reduced motion.

Световой акцент слушает `pointermove` на `document` и использует координаты окна. Наклон схемы остаётся локальным эффектом первого экрана; свет продолжает следовать за курсором в проектах, контактах и кейсах. Reduced motion отключает оба эффекта, touch-ввод не запускает фонарик.

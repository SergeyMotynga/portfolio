## Purpose

FinGuru helps users track personal finances through budget categories, transactions and savings goals. The team built it for a hackathon, using a simulated banking integration for the demonstration.

## My work

- Developed the FastAPI backend and financial data models.
- Implemented one-time-code authentication, a demo sign-in flow and session renewal.
- Worked on budget categories, transactions and savings goals.
- Added push notifications through Firebase.
- Integrated mobile screens with the API, sessions and notifications.

## Technical approach

The backend uses PostgreSQL and Redis. The team's mobile client is built with Flutter. My work covered the backend and selected client-integration tasks alongside other contributors.

I presented the project at a hackathon.

## Purpose

Daily Organizer brings everyday tasks and personal projects together. Users can schedule tasks, repeat them, view them in a calendar and move project tasks between columns.

## My work

- Build the API and interface, connecting user workflows to persistent data.
- Implement authentication and refresh-token sessions.
- Handle dates, deadlines, recurring schedules and time zones.
- Develop day, calendar, archive and filtered task views.
- Add personal projects, columns, board and list views, column renaming and reordering.
- Maintain database migrations and integration checks for core operations.

## Technical approach

The backend uses FastAPI, SQLAlchemy and PostgreSQL, with React on the frontend and Alembic for schema changes. Kanban projects are implemented in the development version; the application remains under active development.

## Для чего нужен проект

В сервисе можно создать проект, собрать команду и указать роль каждого участника в этом проекте. Для релиза можно задать версию, плановую дату и ответственных. Отдельный список показывает ближайшие релизы по всем проектам.

## Что я делал

- Спроектировал модель данных и написал API для проектов, участников, ролей и релизов.
- Разработал веб-интерфейс для ведения проектов, команд и релизов, включая списки задач внутри релиза.
- Реализовал вход через корпоративную учётную запись и административный раздел для управления доступом.
- Подготовил миграции базы данных и конфигурацию контейнерного запуска.

## Технический подход

Роль участника хранится в его назначении на проект, поэтому один сотрудник может выполнять разные роли в разных командах. Ответственные за релиз назначаются отдельно. API написан на FastAPI, данные хранятся в PostgreSQL, интерфейс разработан на React и TypeScript.

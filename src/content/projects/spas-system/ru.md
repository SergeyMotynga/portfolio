## Для чего нужен проект

SPAS System помогает исследовать временные ряды и находить необычные участки. Пользователь загружает данные, выбирает параметры анализа и просматривает результаты на графиках.

## Что я делал

- Разрабатывал интерфейс загрузки временных рядов.
- Добавлял настройку параметров анализа и отображение результатов.
- Работал над графиками и взаимодействием интерфейса с сервером.
- Интегрировал Streamlit-приложение с API командной системы.

## Технический подход

Streamlit и pandas используются для работы с данными и визуализации. Серверная часть на FastAPI предоставляет API анализа; Docker используется для запуска компонентов. Мой вклад сосредоточен на интерфейсе и его интеграции, методы обнаружения аномалий — часть общего командного решения.

После работы над проектом выступил с ним на конференции по приглашению.

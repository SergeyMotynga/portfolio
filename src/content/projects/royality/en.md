## Purpose

Royality is a team-built social application. Users manage profiles, follow each other, publish posts with images and interact through reactions and comments.

## My work

- Developed server infrastructure, authentication and profile management.
- Added follows, avatars and posts with or without images.
- Implemented file uploads to S3-compatible storage.
- Worked on reactions, comments and Firebase push notifications.
- Contributed to mobile-screen, session and notification integration with the backend.

## Technical approach

The server uses FastAPI and PostgreSQL. Media files live in S3-compatible storage, while Firebase handles push notifications. The team's mobile client uses NativeScript and Vue.

My contribution covers backend development and selected client-integration tasks. The interface was developed alongside other team members.
